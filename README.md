# 通用网页图片/视频抓取工具 (v17)

一个带 GUI 的通用网页图片/视频抓取工具，支持自定义网址抓取，抓取的图片按帖子目录分类保存。

## 功能特性

- **通用网址抓取**：粘贴任意网址即可抓取（论坛、图站、分类页、单页）
- **帖子目录分类**：抓取后按帖子标题自动分文件夹保存
- **四种抓取模式**：自动 / 单个网页 / 论坛列表页 / 全站抓取
  - 全站抓取：入口是列表页时自动按"列表翻页+进详情页"抓全部；否则 BFS 遍历整站
- **自定义保存位置**：默认保存在程序目录下 `TU` 文件夹
- **图片/视频可选**：勾选决定是否抓取图片或视频
- **线程数可调**：1~20 并发下载
- **登录接口**：部分需登录的网址可用内置登录窗口获取 Cookie（`登录窗口.exe`）
- **代理支持**：可勾选启用代理，代理地址自动记忆
- **网址历史/收藏**：自动记录历史，可收藏常用网址
- **任务列表**：实时进度、状态、缩略图预览、统计栏
- **预览列表**：先抓列表确认内容，再点"开始抓取"下载
- **分页界面**：任务列表 / 运行日志 两个页签
- **页码控制**：0=全部翻到底，或指定翻页数
- **下载引擎可选**：内置（多线程分段，无需装任何软件）/ IDM / aria2 / 自动检测
- **内置多线程分段**：单文件按 Range 并发分段下载再合并，速度接近 IDM/aria2，无需外部工具
- **下载容错**：断点续传 + 完整性校验，失败自动重试，损坏文件自动清理
- **停止响应**：点停止立即中断（含网络请求级中断）

## 文件说明

| 文件 | 说明 |
|------|------|
| `grabber_gui.py` | 主程序（GUI），打包入口 |
| `webgrab_core.py` | 核心抓取逻辑 |
| `login_window.py` | 登录辅助窗口（独立进程） |

## 打包为 EXE

```bash
python -m PyInstaller --onefile --windowed --name "网页图片视频抓取" \
  --hidden-import webgrab_core \
  --hidden-import PIL --hidden-import PIL._tkinter_finder \
  grabber_gui.py

python -m PyInstaller --onefile --windowed --name "登录窗口" \
  --hidden-import webview login_window.py
```

依赖：`Pillow`（缩略图）、`pywebview`（登录窗口）。

## 使用说明

1. 在"列表页网址"填入目标网址（如论坛版块、图站分类页）
2. 选择抓取模式、页码（0=全部）、线程数
3. 可选：点"预览列表"先确认识别到的帖子，再点"开始抓取"
4. 保存位置默认在程序目录 `TU` 下，可自定义

- **v13**：新增"预览列表"功能；修复跨线程 UI 操作
- **v12**：全站抓取对列表页自动走"翻页+详情页"；停止立即生效；超时调短
- **v11**：标题加版本号显示
